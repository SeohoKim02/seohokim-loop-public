# Contributing to SeohoKim Loop

Preserve the existing v0.1 architecture. Keep domain/application logic separate from provider adapters and Electron boundaries. Propose a small, reproducible change before a broad redesign.

Use fictional data and Fake/Mock providers for tests. Do not add live AI calls, cloud fallbacks, credentials, personal history, or model weights. Run `npm test`, `npm run typecheck`, and `npm run build` for code changes. Document any unverified platform or behavior.

Record the source, license, and relevant notices for imported code, prompts, images, and test data. AI-assisted code still needs review for third-party rights and security. Submit only work you have permission to contribute.

The identified project-owned files are licensed under Apache-2.0; see LICENSE and NOTICE. Third-party terms remain separate.
This contribution guide does not transfer anyone's copyright. For ordinary bugs or feature ideas, open an issue with fictional reproduction data. For a change, fork this repository, create a focused branch and submit a pull request with the relevant test results. Maintainer review is required; acceptance and response times are not guaranteed.

Report security issues through the private channel described in the SECURITY.md, never in a public issue containing secrets.
